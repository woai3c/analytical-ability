# 《怎样培养分析能力》原书重点提要

> 本文只保留原书的重要观点、方法、步骤和有助于理解方法的案例，删除重复说明、铺垫及无关细节。内容已由繁体竖排转换为简体横排。
>
> **示例标记：**“原书示例”来自原书；“补充示例”是为了说明今天如何使用该方法而增加的现代案例，不属于原书内容；“行业说明”依据文末列出的现代专业资料。

## 全书核心

### 分析力的含义

分析力是把复杂对象分成可观察的部分，了解各部分的性质、差异和关系，再重新组合成结论，并据此作出判断和行动的能力。

### 分析的三个基本阶段

1. **分开**：把混合、复杂或模糊的对象拆成较小单位。
2. **了解**：观察各单位的性质、数量、差异、因果和相互关系。
3. **组合**：把局部认识重新放回整体，形成解释、判断、预测或行动方案。

三个阶段需要反复往返，不能机械地只做一次。只拆分而不重组，会失去整体意义；只看整体而不拆分，又容易停留在模糊印象。

### 全书反复强调的原则

- 信息本身不是力量，经过选择、分类、比较和解释的信息才有用。
- 分析的目的不是增加知识，而是提高判断和行动的准确性。
- 正确答案可能不止一个，结论取决于目的、条件、时间和证据。
- 信息越多不一定越好，关键是信息是否相关、可靠、及时和可处理。
- 图解、卡片、清单和数量化表达可以降低复杂度，使关系更清楚。
- 分析需要同时关注局部与整体、投入与产出、现状与变化。
- 分析结果必须经过验证，并根据实际行动结果继续修正。
- 分析力不是少数专家的特殊能力，而是可以通过日常练习培养的能力。

## 第一章 不可或缺的分析力

**原书页码：13-29**

- 现代竞争越来越依赖信息和分析，掌握资料并不等于掌握优势。
- 公开资料经过搜集、分类和组合，也能产生别人没有发现的价值。
- 商业、医疗、司法、管理、路线选择、购物和家庭生活都需要分析。
- 所谓“头脑好”，不只是记忆快或知识多，更重要的是能从信息中导出方针。
- 正确行动来自准确分析；分析若不转化为行动，就没有完成目的。
- 灵感通常建立在长期观察、知识积累和反复比较之上。
- 分析力可以提高预测成功率，但不能保证预测绝对正确。
- 每个人都需要分析社会变化、工作条件和人际关系。
- 工作能力强的人，通常能更快发现问题、掌握条件并采取适当行动。
- 良好人际关系需要分析自己和他人的立场、性格与行为。

**本章核心：信息只有经过分析并转化为行动，才会形成真正的力量。**

## 第二章 了解分析的本质：从自己和他人开始

**原书页码：30-58**

### 分开

- 根据分析目的选择拆分方式，可以按功能、时间、位置、对象、原因或重要性拆分。
- 拆分单位不能过大，否则看不清差异；也不能过细，否则失去整体关系。
- 不同问题可能需要不同拆分方式，不存在适用于一切对象的固定分类。

### 了解

- 了解每个部分的性质、数量、价值、变化和相互影响。
- 通过比较寻找相同点、不同点、异常项和关键因素。
- 区分事实、意见、推测和未知信息。
- 信息数量应以能支持判断为标准，不应无目的地无限搜集。

### 组合

- 把各部分重新组织起来，说明它们如何共同产生整体结果。
- 组合不是恢复原状，而是形成新的解释、结构或行动方案。
- 分析过程中出现的灵感可以使用，但必须接受事实检验。

### 辅助方法

- **图解**：用位置、线条、层级和箭头表示关系。
- **减少要素**：先抓住少数关键因素，再逐步增加细节。
- **扩大差异**：通过分类、比例、评分或对比，使细小差异变得明显。
- **卡片法**：把一条资料写在一张卡片上，进行移动、分类和重新组合。
- **数量化**：用评分、权重、平均值或方程式表达判断依据。
- **利用副产品**：分类失败项、异常项和附带发现也可能形成新的问题线索。

### 完整应用示例（补充示例）

**目标：降低一家外卖店的差评率。**

1. **分开**：把差评按餐品、包装、配送、客服和价格拆开；再按门店、日期、时段和订单类型细分。
2. **了解**：比较各类差评的数量和占比，查看差评原文、出餐时间、配送时间、退款记录，并区分事实与顾客推测。
3. **组合**：若数据显示“晚餐高峰出餐慢”同时导致送达温度低、配送超时和客服投诉，就不能把三个现象分别处理，而应把高峰产能不足作为共同问题。
4. **行动与验证**：调整高峰备料和菜单，两周后用相同指标复查。若差评没有下降，再检查原来的解释是否遗漏了其他因素。

**本章核心：分析必须完成“分开、了解、组合”的完整循环。**

## 第三章 了解分析的专门技巧非常有用

**原书页码：59-78**

### KJ 法

- 适用于资料零散、问题混乱、重点尚不清楚的情况。
- 把事实或意见分别写在卡片上。
- 按内容之间的接近程度归类，不先强迫材料进入既定框架。
- 为各组概括主题，再分析组与组之间的关系。
- 从整体结构中找出问题真正的重点。

**原书示例（约第 64—66 页）：**

- 把会议记录中的每一条发言分别写在卡片上；调查报告一页若含多个结论，也拆成“一项一卡”。
- 把内容接近的卡片放在一起并命名，再画出各组之间的关系。原书还以制作书籍索引、整理“人为什么会发胖”等杂乱资料说明这种做法。
- 书中举出广告缺乏吸引力、销量低、代理商不积极等许多纠缠在一起的经营问题，说明 KJ 法适合在尚不知道重点时先让资料自然成组。

**补充示例：分析用户为什么放弃一款记账应用。**

1. 将访谈原话拆成独立卡片，如“第一次不知道从哪开始”“同步经常失败”“会员太贵”“分类太多”。
2. 不预设结论，按内容接近程度归成“上手困难”“稳定性”“价格”“信息架构”等组。
3. 给每组命名并连接关系。若“分类太多”和“第一次不知道从哪开始”共同指向上手困难，就把它作为待验证的核心问题。
4. 回到流失率、故障日志和价格实验核验；KJ 法负责形成结构，不负责单独证明因果。

**行业说明：**今天通常称为“亲和图（Affinity Diagram）”或 KJ 法。美国质量学会将其列为质量工具，常用于整理大量意见、复杂问题和团队共识，在质量管理、用户研究和工作坊中较常见。

### ABC 分析

- 按价值、重要性、影响或使用频率排序。
- A 类是少数最重要项目，优先投入资源。
- B 类为次要项目，维持适度管理。
- C 类数量可能很多，但单项价值较低，应简化处理。
- 目的不是固定分类，而是把有限精力放在最有影响的部分。

**原书示例（约第 67 页）：**

- 先以衣柜为例：把衣物按价值和需要程度分类，最重要的归 A，中等归 B，价值较低的归 C，再决定管理精力。
- 书中还举库存和质量管理为应用场景，核心不是平均照顾所有项目，而是重点管理少数高价值项目。

**补充示例：管理 1000 种库存商品。**

1. 计算每种商品的“年度耗用价值＝年用量×单位成本”，按高到低排列。
2. 以示例阈值划分：累计价值约占 70%—80% 的少数商品列为 A，下一段列为 B，其余列为 C。实际阈值应按业务风险调整，不是固定定律。
3. A 类逐项预测、频繁盘点并设置严格补货规则；B 类定期检查；C 类用较简单、低成本的批量规则管理。
4. 每月复核分类，因为价格、需求和缺货风险会变化。

**行业说明：**这是库存、采购、供应链和客户价值管理中的经典方法，SAP 等企业软件直接提供 ABC 分类功能。它与帕累托分析都强调“重要的少数”，但两者不是同一个工具：ABC 输出管理等级，帕累托图按频数或成本排列问题并显示累计影响。

### 鱼骨分析

- 把需要解释的问题写在鱼头位置。
- 列出造成结果的主要原因类别。
- 继续追问每一类原因下面的具体原因。
- 检查原因之间是否重复、遗漏或只是表面症状。
- 用于整理复杂原因，不等于自动证明因果关系。

**原书示例（约第 68—69 页）：**

- 原书先把衣柜中的物品分大类，再把皮带等类别继续细分，用“主干—分支—细枝”的形状说明层层拆解。
- 另以写书为例：全书分十章，每章再分十节，每节再分十项，复杂内容便成为可处理的层级结构；也建议用家庭物品和公司业务练习这种分解。

**补充示例：分析订单为什么经常延迟。**

1. 在鱼头写“订单延迟率高”。
2. 建立人员、流程、系统、物料、测量和环境等主骨。
3. 在“流程”下继续写审批等待、批量处理、交接不清；在“系统”下写接口超时、库存数据不同步等候选原因。
4. 对每个候选原因收集时间戳、故障日志和抽样记录，判断它是否真的与延迟同时出现并具有足够影响。
5. 先处理证据最强、影响最大且可控制的原因，实施后复测延迟率。

**行业说明：**现代业界通常称为“鱼骨图、因果图或石川图”，是质量管理中非常知名的七种基本质量工具之一。需要注意：原书的例子更偏“层级分类”，现代鱼骨图则主要用于组织潜在原因；图上的分支只是待验证假设，不是因果证据。

### 价值分析

- 明确对象必须完成的功能。
- 比较功能的重要性和实现功能所需成本。
- 删除不必要功能、过度规格和无价值支出。
- 寻找能保持必要功能但成本更低的替代方案。

**原书示例（约第 70—71 页）：**

- 菜肴需要的是味道、营养等功能；如果猪肉能满足必要功能，就应比较是否必须使用更贵的牛肉。
- 衣服应先问用途是礼服还是日常穿着，再判断是否需要定制、多个尺寸或过多颜色。
- 书中还比较精装书与普通书、昂贵酒与普通替代品，并借多用途刀具说明：先确定真正需要的功能，再评价成本。

**补充示例：降低注册环节的身份核验成本。**

1. 把必要功能写清楚：阻止高风险欺诈、满足法规要求、让正常用户顺利注册。
2. 记录当前方案的单次费用、通过率、等待时间、人工复核量和欺诈损失。
3. 比较替代方案，如更换接口供应商、只对高风险用户加强核验、将部分人工复核改为异步处理。
4. 不能只选最便宜方案；必须同时验证安全、合规、通过率和体验是否达到最低要求。
5. 选择在必要功能不下降前提下总成本更低的方案，并在上线后持续测量。

**行业说明：**现代通常称“价值分析（VA）”或“价值工程（VE）”，在制造、工程、建设和采购中有成熟的专业体系。其核心仍是功能分析，并在功能、性能、质量、安全与成本之间提高整体价值。

### 模拟实验

- 在正式执行前，以模型、假设、小规模试验或情境推演验证方案。
- 改变一个或几个条件，观察结果如何变化。
- 用模拟发现原分析中的遗漏、风险和错误假设。

**原书示例（约第 72—73 页）：**

- 生日宴会前先试做菜谱，改变面粉种类或牛奶温度，直到结果稳定。
- 搬家前用平面图或模型试排家具；驾驶训练先用模型；建筑先看图纸和模型。
- 新产品不立刻全国推广，而是先在一个地区试销，观察反应后再决定扩大范围。

**补充示例：上线新的客服分流规则。**

1. 先用历史工单离线回放，检查规则会把哪些问题分错。
2. 再让 5% 的新工单进入试点，其余维持原流程作为对照。
3. 预先规定正确率、首次响应时间、转人工率、投诉率和停止条件。
4. 每次只修改一个主要条件，记录版本和输入；达到安全标准后逐步扩大，否则回退并修正假设。

**行业说明：**模拟、原型、试点和测试市场广泛用于工程、运营、产品开发和政策评估，但它们是一个方法族，不是一套完全统一的步骤。结果是否可信取决于模型是否接近现实、输入数据是否可靠，以及是否做过验证。

### 集团思考

- 通过多人观点补足个人知识和视角的限制。
- 先充分提出意见，再进行分类、比较和选择。
- 需要保留反对意见，防止从众使错误结论被放大。

**原书示例（约第 73—75 页）：**

- 书中以周年纪念活动的策划会议说明集体发想：有人提出“搜集大家喜欢的东西”，其他人沿着这个想法继续增加、组合和改进方案。
- 书中规则包括：提出阶段不批评；尽量增加数量；允许自由甚至看似离题的想法；欢迎沿用、组合和改进别人的想法。

**补充示例：寻找提高新用户次日留存的方法。**

1. 六名参与者先各自静默写卡片十分钟，避免最先发言的人支配方向。
2. 发想阶段只澄清意思，不评价可行性；允许在别人的点子上继续延伸。
3. 发想结束后再用 KJ 法归类，并从影响、证据、成本和风险四项评分。
4. 保留少数意见和反对理由，将最高分方案变成小实验。必须把“发想”和“评价”分成两个阶段。

**行业说明：**这部分对应今天非常普及的“头脑风暴（Brainstorming）”。原书的基本规则与美国质量学会列出的规则高度一致。不过头脑风暴只用于产生候选方案，不能以“大家都同意”代替事实验证。

### PERT

- 把工作分解成可以管理的活动。
- 明确活动之间的先后依赖关系。
- 估计每项活动所需时间。
- 找出影响总工期的关键步骤。
- 根据执行情况更新次序和时间估计。

**原书示例（约第 76—78 页）：**

- 购物前把各项行动写成卡片，按“出门前—到店后—结账前”的依赖顺序排列，避免遗忘和来回折返。
- 书中还以新产品开发、开店、建筑工程和跨部门活动说明：先把任务全部列出，再连接先后关系，找出影响完成日期的工作。

**补充示例：安排一款手机应用发布。**

1. 列出需求确认、界面设计、接口开发、客户端开发、联调、测试、商店审核和发布等活动。
2. 标明依赖：接口和客户端可部分并行，联调必须等待两者达到可用状态，系统测试必须在联调之后。
3. 对不确定活动估计乐观时间 O、最可能时间 M、悲观时间 P；经典 PERT 期望时间为 `(O + 4M + P) / 6`。
4. 画出网络并计算最长依赖路径。若联调—测试—审核位于关键路径，延误其中任一项都会推迟总发布日期。
5. 每周用实际进度重算。对于多路径和强相关风险，复杂项目还应使用进度风险分析或蒙特卡洛模拟，而不能只依赖单个平均时间。

**行业说明：**PERT 是项目管理史上的经典方法，因美国海军“北极星”导弹项目而闻名，今天 PMI 术语中仍保留其三点估算定义。不过原书把它简化成“卡片排序＋任务网络”；现代项目管理还常结合关键路径法、前导图和进度风险模拟。

### 这些方法在业界的知名程度（补充资料，非原书）

| 原书方法 | 现代常用名称 | 行业地位与常见场景 |
| --- | --- | --- |
| KJ 法 | 亲和图、Affinity Diagram、KJ Method | 成熟且常用；质量改进、用户研究、需求整理和团队工作坊 |
| ABC 分析 | ABC Inventory/Customer Analysis | 供应链、库存、采购和客户分层中的经典方法 |
| 鱼骨分析 | 鱼骨图、因果图、石川图 | 非常知名；七种基本质量工具之一，常用于根因分析的候选原因整理 |
| 价值分析 | Value Analysis、Value Engineering | 有专业标准和职业体系；制造、工程、建设和采购 |
| 模拟实验 | Simulation、Pilot、Prototype、Test Market | 各行业广泛使用，但属于方法族，具体规范随领域而变 |
| 集团思考 | Brainstorming | 极为普及；创意产生、问题解决和工作坊，但必须与后续评价分开 |
| PERT | Program Evaluation and Review Technique | 项目管理经典方法；现代复杂项目通常与其他排程和风险工具结合 |

不能把“出名”当成“适用于一切问题”。这些方法分别解决资料整理、优先级、原因假设、功能成本、低风险验证、集体发想和项目排程，选错工具仍会得到无效结果。

**本章核心：不同方法解决不同问题，必须先判断问题类型，再选择工具。**

## 第四章 要把握时势

**原书页码：79-100**

- 同一社会现象可能有多个合理解释，不应急于寻找唯一答案。
- 大变化往往由许多微小变化积累而来，需要持续观察。
- 商品、价格、广告、流行语、服饰、文学、娱乐和消费行为都能反映时代变化。
- 分析现象时要同时考虑当时的社会、经济和文化背景。
- 同一现象在不同背景中可能代表不同意义。
- 分析系统时应同时观察“入口”和“出口”，即投入和产出。
- 正式统计之外，还应搜集现场观察、社会意见和行为变化等活的情报。
- 巨大指标用于了解总体方向，但可能掩盖局部差异。
- 先行指标能比最终结果更早反映变化，应长期追踪验证。
- 分析有代表性的人物、作品和大众文化，可以辅助判断社会心理。
- 不能根据单项新闻或单月数据判断趋势，应观察连续变化和多项指标。

**本章核心：把握时势要结合背景，持续追踪多个指标，并寻找变化的先行信号。**

## 第五章 公司的现状和对将来的预测

**原书页码：101-122**

- 公司应每隔三至五年进行一次系统分析，不能等危机出现后才检查。
- 分析企业不能只看当期利润，还要看收益性、安全性、发展性和外部环境。

### 收益性

- 检查收入、成本、利润和投入资源之间的关系。
- 判断企业是否真正创造收益，而不是只看营业额增长。

### 安全性

- 检查现金、负债、资金周转、成本结构和经营稳定程度。
- 当前赚钱不等于安全，资金链和成本失控仍可能造成危机。

### 发展性

- 比较不同时期的人员、薪资、投资、产出、市场和技术变化。
- 判断增长是稳定、低度还是已经停滞。

### 其他关键因素

- 总经理的观念和行为会反映公司的基本方针和风格。
- 人才、资金和资产共同决定企业能力，人才是持续发展的关键。
- 分析现有产品是否仍有竞争力，并检查研究开发能否形成未来产品。
- 判断所在产业是上升、稳定还是衰退。
- 公司外部形象和社会评价会影响顾客、人才和合作关系。
- 关联公司和合作伙伴的稳定性也会影响企业未来。

**本章核心：企业健康必须从利润、现金、成长、人才、产品、行业和社会评价等多个维度综合判断。**

## 第六章 洞察工作本质的分析力

**原书页码：123-140**

- 工作的基本任务是发现问题、理解问题并解决问题。
- 解决前必须明确目标、现状、原因、限制和成功标准。
- 区分问题的表面症状与真正原因。
- 日常工作可以从模仿成熟做法开始，再分析其中原理并形成自己的方法。
- 学习别人的经验，重点是提炼能够迁移的步骤，而不是复制表面动作。
- 使用 PERT 分解任务、排列依赖关系、估计时间并找出关键步骤。
- 提高效率不仅是加快速度，还包括减少错误、返工、等待和浪费。
- 工作素质同时包括准确性、完整性、稳定性和可重复性。
- 时机决定行动效果，正确的事在错误时间执行也可能失败。
- 评价工作要同时看质量、时间、成本、风险和实际结果。

**本章核心：先理解工作的目的和结构，再决定步骤、资源、时机与评价标准。**

## 第七章 分析别人的眼光

**原书页码：141-156**

- 人际合作需要理解对方的立场、性格、行为方式和利益关系。
- 对人的判断不能只依赖一次接触，应在不同场景中持续观察。
- 第一印象影响很大，但只能作为初步假设，需要后续事实修正。
- 动作、说话方式、兴趣、嗜好和长期行为可以提供性格线索。
- 一个人所选择的朋友和群体，能反映部分价值取向和生活方式。
- 游戏等较自由的活动可能显露竞争、合作、耐心和规则意识。
- 个人生活史比孤立行为更能解释性格形成和行为模式。
- 分析他人时也要检查自己的好恶、利益和先入之见。
- 原书包含从面相、外形和颜色偏好推断性格的内容，这些属于原书观点，不能代替长期行为证据。

**本章核心：了解一个人要依靠多场景、长期、可验证的行为，第一印象不能直接成为结论。**

## 第八章 了解真正的自己

**原书页码：157-176**

- 看清自己的能力、愿望、立场和限制，可以使行动更稳定。
- 自我分析不是给自己贴固定标签，而是观察自己在不同环境中的反应。
- 区分自己真正喜欢的事、外界期待的事和暂时冲动。
- 明确未来愿望，并检查愿望是否具有现实条件和行动路径。
- 只靠内省不够，还要利用家人、朋友和同事的反馈。
- 从过去经历中寻找反复出现的兴趣、选择、成功、失败和行为模式。
- 个人收藏和阅读的书籍可以反映长期关注、价值和兴趣。
- 回顾童年游戏、朋友、老师和家庭影响，有助于理解个性来源。
- 比较理想中的自己、公开表现的自己和实际行动中的自己。
- 人在不同场景中可能表现出不同面貌，应分析触发这些差异的条件。

**本章核心：自我认识需要内部反省、历史回顾、现实行为和外部反馈相互验证。**

## 第九章 分析力在家庭生活中的应用

**原书页码：177-192**

- 日常行动可以分为经过分析的行动和未经分析的习惯性行动。
- 通过记录和复盘，可以改善购物、饮食、家务、预算、健康和迁居决定。
- 家庭成本不只是购买价格，还包括使用时间、耐用性、维护和替代成本。
- 分析支出可以发现重复购买、闲置物品和不必要浪费。
- 厨房可以按工厂流程分析：储存、准备、烹调、用餐和清洁。
- 厨房布局应减少无效移动，并协调水、火、工作台和储物空间。
- 饮食需要分析营养、数量、价格、口味、时间和家庭成员需要。
- 家计簿不只是记账，还要比较预算与实际支出，并据此调整下月计划。
- 教育子女需要观察实际行为、成长环境、兴趣和发展变化。
- 健康分析要记录症状、生活习惯和变化，必要时应由专业人员判断。
- 迁居需要综合分析价格、交通、环境、空间、工作和家庭需求。

**本章核心：通过记录、比较和流程分析，把家庭中的习惯性行动转化为有依据的决定。**

## 第十章 提升分析力

**原书页码：193-212**

- 遇到概念先查字典和工具书，确认词义、用法和边界。
- 使用清单把复杂问题变成可检查项目，防止遗漏。
- 建立基本单位，把复杂对象拆成能够单独处理的小块。
- 与他人来回讨论，用提问和反驳检验自己的观点。
- 象棋、填字、拼图等益智游戏可以训练分类、假设、预测和修正。
- 游戏训练必须迁移到现实问题，才会形成真正的分析能力。
- 保持好奇心，对习以为常的现象继续追问“为什么”。
- 有效思考需要持续用脑、记录问题、形成假设并寻找证据。
- 不只观察成果，也要观察废弃物、异常物和副产品，因为它们能反映系统内部状态。
- 使用比喻可以帮助理解陌生问题，但必须检查相似点和不同点。
- 收集格言和古谚，可以作为观察人类经验的材料，但不能代替事实分析。
- 重新检查分析的含义：分析不仅是分开，还包括了解、组合和行动。
- 一个问题可能存在多个答案，应从不同角度解释并检验。

**本章核心：分析力来自长期、反复和有意识的思考训练。**

## 原书方法总表

| 方法 | 解决的问题 | 主要输出 |
| --- | --- | --- |
| 分开、了解、组合 | 如何理解复杂对象 | 结构化解释或行动方案 |
| 图解 | 关系不清楚 | 关系图、流程图或结构图 |
| 卡片法 | 资料零散 | 分类后的资料组 |
| KJ 法 | 重点不明确 | 问题结构和核心主题 |
| ABC 分析 | 资源有限、项目过多 | 优先级分类 |
| 鱼骨分析 | 原因复杂 | 分层原因结构 |
| 价值分析 | 成本与功能不匹配 | 保持功能、降低浪费的方案 |
| 模拟实验 | 方案风险未知 | 验证结果和风险清单 |
| 集团思考 | 个人视角有限 | 多视角结论和异议 |
| PERT | 工作步骤复杂 | 依赖关系、关键步骤和进度计划 |
| 指标追踪 | 判断趋势 | 趋势结论和预警信号 |
| 企业多维分析 | 判断企业健康 | 收益、安全、成长和外部环境结论 |
| 自我与他人分析 | 理解行为 | 经多方证据验证的行为模式 |
| 记录与复盘 | 改善日常决定 | 差异、原因和修正行动 |

## 原书最终结论

分析不是把事物切碎，而是为了更准确地重新理解整体。完整分析必须从事实出发，经过分开、了解和组合，形成可以验证的判断，并落实为行动；行动结果又成为下一轮分析的新资料。
